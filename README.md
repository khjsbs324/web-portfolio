# 김혜지 프로필 포트폴리오 · 시안3

Figma의 `강사 프로필 > 시안3`(802:934)을 HTML, CSS, jQuery, GSAP으로 구현했습니다.

## 실행

`index.html`을 열거나 `python -m http.server 5173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:5173 에 접속하세요.

## 구성

- 베이지 콜라주 인트로 → 프로필 → 가로 프로젝트 목업 3개 → 마지막 소개 문구
- 이미지: `이미지주소.md`의 링크를 직접 사용합니다. 가지 장식은 브라우저에서 CDN 오류가 확인되어 GitHub 원본 주소로 연결했습니다.
- `js/image-fallback.js`: CDN 이미지가 실패하면 원본 주소로 한 번 전환합니다.
- 하단 목업 3개는 회색 박스로 유지합니다.
- `css/style.css`: 시안 배치와 모바일 반응형 스타일
- `js/main.js`: 인트로의 순차 등장, 프로필의 페이드 업, 프로젝트 가로 스크롤, 마지막 글자의 흐림과 상승 효과
- `vendor/`: jQuery 3.7.1, GSAP·ScrollTrigger 3.13.0
- `assets/fonts/`: Noto Sans KR 가변 글꼴 서브셋

## 애니메이션과 조작

인트로 이미지와 카드가 차례로 드러나고 꽃 장식은 스크롤에 따라 천천히 이동합니다. 마지막 문구는 화면 진입 시 글자별로 흐림이 걷히며 떠오르고, 양쪽 가지도 천천히 나타납니다.

데스크톱에서는 프로젝트를 고정하여 세로 스크롤을 가로 이동으로 연결합니다. 목록에 포커스를 두면 방향키와 Home/End를 사용할 수 있습니다. 모바일에서는 터치 가로 스크롤을 사용합니다.

동작 줄이기 설정 또는 JS 미사용 시 콘텐츠를 정적으로 표시하고 프로젝트는 기본 가로 스크롤을 사용합니다. 데스크톱의 고정 스크롤 때문에 실제 페이지 높이는 원본 3507px보다 길어질 수 있습니다.

푸터에는 작은 꽃 16송이를 가지 방향에 맞춰 배치했습니다. 스크롤로 푸터에 진입하면 좌우에서 한 송이씩 차례로 피어나며, 빠르게 스크롤해도 개화 순서는 유지됩니다. 배너 좌상단 꽃은 무채색에서 서서히 색을 되찾습니다.
